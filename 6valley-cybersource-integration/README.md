# CyberSource Payment Gateway Integration for 6valley

Complete integration package for adding CyberSource payment gateway to your 6valley e-commerce platform.

## Features
- Full CyberSource Secure Acceptance integration
- Test Mode and Live Mode support  
- Admin panel configuration
- Secure payment processing
- Multi-currency support

## Quick Start

1. Copy all files to your 6valley installation
2. Run `php artisan migrate`
3. Add routes to `routes/web.php`
4. Configure in Admin Panel
5. Test with card: 4111111111111111
